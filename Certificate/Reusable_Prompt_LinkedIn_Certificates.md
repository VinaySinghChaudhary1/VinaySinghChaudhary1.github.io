# Reusable prompt — "Add my new IIT Madras certificate to LinkedIn"

Save this. Next time you finish a new course/certificate from IIT Madras (or want to redo an old one), open a new chat with your **Certificate** folder connected, drop the new certificate PDF(s) into that folder, and paste the prompt below — filling in the one line marked `[UPDATE THIS]`.

---

**Prompt to paste:**

> I've added a new certificate PDF to my `Certificate` folder — `[UPDATE THIS: filename, e.g. "Diploma Certificate - Diploma In Data Science.pdf"]`. This is from my IIT Madras BS in Data Science and Applications program (Roll No. 22F2001153).
>
> Please do the following, the same way you did before:
>
> 1. Open the new certificate PDF in the folder and extract the official certificate name, issuing body, roll number, and any dates printed on it.
> 2. Decode the QR code embedded in the certificate to get its document-verification URL (use it as the Credential URL).
> 3. Cross-check the exact program/course terminology against the IIT Madras BS program pages (study.iitm.ac.in/ds — overview and academics pages) so the certificate name and the "what it covers" description are accurate.
> 4. Suggest 8–10 relevant LinkedIn Skills to tag for this specific certificate, based on the courses it covers.
> 5. Produce a Word document (.docx) laid out exactly like LinkedIn's "Add license or certification" pop-up, in this field order: Name, Issuing organization, Issue date, Expiration date, Credential ID, Credential URL, Skills to add, Media to attach — plus a short "what this certificate covers" note under each entry.
> 6. Use "Indian Institute of Technology Madras (IIT Madras)" as the issuing organization, and Roll No. 22F2001153 as the Credential ID, consistent with my earlier certificates.
> 7. If this new certificate should be added *alongside* my existing ones (Foundation Certificate, Advanced Certificate in Programming and Application Development, Diploma in Programming, Advanced Certificate in Machine Learning and Data Science), please also tell me where in that timeline the new one slots in.
> 8. Flag anything printed unclearly (e.g. missing issue month) rather than guessing, so I can double check my IITM student dashboard.
>
> Reference links if useful: study.iitm.ac.in/ds, study.iitm.ac.in/ds/academics.html, my LinkedIn (linkedin.com/in/vinay-singh-chaudhary), my GitHub (github.com/VinaySinghChaudhary1).

---

### Notes for future-you

- This only works well if the **Certificate** folder (or wherever you save new certificate PDFs) is connected to the chat first — check the folder/paperclip icon before pasting the prompt.
- If a certificate is a scanned image instead of a text-based PDF, say so in the prompt — the extraction step needs to know to read it as an image.
- If you finish the **Diploma in Data Science** (the one currently in progress), mention that explicitly — it should replace the "Advanced Certificate in Machine Learning and Data Science" entry on LinkedIn the same way the Diploma in Programming certificate replaced/complemented the Advanced Certificate in Programming and Application Development.
